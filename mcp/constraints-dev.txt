# Pinned dependency set for reproducible CI and dev installs.
#
# WHY: pyproject.toml declares open ranges (`mcp>=1.0`, `httpx>=0.27`, ...) —
# correct for a library's consumer contract, but it means CI resolves fresh
# versions on every run. That has broken this repo before: an unpinned ruff
# 0.16.0 expanded its default rule set and failed the build mid-PR, and
# pytest-httpx API drift cost debugging time twice. This file pins the exact
# transitive set CI installs, so a dependency release can never break a build
# that touched none of it. Dependabot proposes bumps as reviewable PRs instead.
#
# USE:        pip install -e ".[dev]" -c constraints-dev.txt
# REGENERATE: python3.11 -m venv /tmp/lockgen && /tmp/lockgen/bin/pip install -e ".[dev]"
#             /tmp/lockgen/bin/pip list --format=freeze \
#               | grep -v '^threat-intel-mcp' | grep -viE '^(pip|setuptools|wheel)=='
#
# Generated from Python 3.11 (the lowest supported version); verified to install
# and pass the full suite on 3.11, 3.12, and 3.13 — all three resolve this same
# set, so one file serves the whole CI matrix.
